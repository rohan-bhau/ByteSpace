# ByteSpace

A responsive online learning platform landing page built from the provided Figma design.

## Live Demo

https://bytespace-iota-amber.vercel.app/

## GitHub Repository

https://github.com/rohan-bhau/ByteSpace

## Features

- Responsive ByteSpace landing page
- Hero section with course search
- Course categories and course cards
- Learning path/category section
- Creator-focused CTA sections
- Community testimonials
- Responsive navigation and footer
- Login page
- Signup page

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Design

The landing page was implemented based on the provided Figma design while adapting layouts and element sizes where necessary to maintain responsive behavior across screen sizes.

## Additional Work

Login and Signup pages were also implemented as additional pages beyond the main landing page requirement.

## Deployment

The project is deployed on Vercel and is publicly accessible through the live demo link above.
